# Notas & Journal

O **Notas & Journal** é uma aplicação de organização pessoal inspirada no conceito de **Bullet Journal**, criada para ajudar os usuários a organizar tarefas, compromissos, notas e hábitos de forma simples e minimalista.

O projeto contará com duas soluções integradas:

- **Web:** para organizar e visualizar tarefas, notas, hábitos e registros de forma mais completa.
- **Aplicativo Mobile:** para permitir o registro e acompanhamento das atividades de forma rápida e prática.

### Funcionalidades

- Criação, edição e exclusão de tarefas;
- Marcação de tarefas como concluídas;
- Organização por datas e categorias;
- Criação de notas e eventos;
- Visualização em formato de lista e Journal;
- Acompanhamento de hábitos;
- Gráficos de tarefas concluídas ao longo do tempo;
- Indicadores de progresso dos hábitos;
- Histórico de atividades;
- Interface minimalista;

### Acompanhamento

A aplicação contará com uma área de acompanhamento onde o usuário poderá visualizar seu progresso, como:

- Quantidade de tarefas concluídas e pendentes;
- Tarefas concluídas por dia ou semana;
- Sequência de dias realizando determinado hábito;
- Percentual de conclusão das metas;
- Histórico de hábitos e atividades.
